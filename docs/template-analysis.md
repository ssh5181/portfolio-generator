# 서식 분석 (1단계)

5개 서식은 같은 뼈대(Ⅰ 수업운영 → Ⅱ 수업결과물 → Ⅲ 수업성찰)를 공유하고, 아래 차이만 있다.
엔진은 칸 위치(행/열 번호)가 아니라 **라벨 텍스트**로 칸을 찾기 때문에 서식마다 열 구성이 달라도 동작한다.

## 입력 유형별 칸

| 유형 | 칸 |
|---|---|
| 체크 | 교과유형, 수강학년, 운영형태(+인원), 분반여부(+분반 수), 전용강의실 사용, 구분(서식 유형 자동), 개인정보 동의, 현장전문가 참여 역할(IC 서식, 기타 내용) |
| 단답 | 개설학과(전공), 교과목명, 학점-강의-실습, 수강규모, 성명, 소속, e-mail, Tel, 문제/프로젝트명·출처·개발일자·수정일자, 현장명·전문가 성명·직급·이메일 |
| 서술 (AI 대상) | 수업목적, 수업 운영 및 평가 전략 9칸, 주차별 활동(교수자/학습자, 주차 수만큼 행 자동 추가), 현장연계사항, 수업성찰 4~5칸 |
| 첨부 (이미지) | 워크시트/평가시트, 수업활동사진(2장씩 한 줄), 수업결과물 샘플 |

## 서식별 차이

| | PBL | PjBL | FL | IC-PBL | IC-PjBL |
|---|---|---|---|---|---|
| Ⅱ-1 블록 | 문제/시나리오 | 프로젝트 | 수업 전 활동(사전학습자료) | 문제/시나리오 | 프로젝트 |
| 오리엔테이션 라벨 | 오리엔테이션 | 〃 | 〃 | 현장 연계 기반 오리엔테이션 | 〃 |
| 수업활동사진 칸 | 있음 | 있음 | 있음 | 있음 | **없음** |
| 현장연계 사항 표 | - | - | - | 6번 | 5번 |
| 현장연계 성과 및 한계 | - | - | - | 있음 | 있음 |
| 구분 체크박스 | 있음 | 있음 | 있음 | 있음 | 없음(고정 텍스트) |
| 섹션 수 | 1 | 1 | 1 | 1 | 2 |

## 조립 방식

- 체크박스는 한글 양식 개체(`hp:checkBtn`)라 값만 `CHECKED`로 바꾼다.
- 회색 안내문(※ …)이 있던 칸은 안내문을 지우고 본문 글자 모양으로 채운다. 서술형 칸은 왼쪽 정렬·위쪽 붙임.
- 이미지는 `BinData/`에 넣고 `content.hpf`에 등록한 뒤 "글자처럼 취급" 그림으로 삽입한다. 쪽 폭에 맞춰 축소, 첨부가 있으면 해당 섹션의 작성 지침 문단은 삭제한다.
- 편집한 문단은 줄 배치 캐시를 지워 한글이 열 때 다시 배치하게 한다.
